# 新生入學統計調整紀錄（2025/09/29）

## 目標

修正 `Form2.cs` 新生入學方式統計表「按戶籍地分」的學校所在地縣市取得方式。

---

## 問題原因

`LocalCounty` 原本固定為空字串：

```csharp
string LocalCounty = "";
```

造成「戶籍位於本縣市 / 戶籍非位於本縣市」判斷錯誤（幾乎所有學生都會被歸入「非本縣市」，除非學生 `County` 也是空字串）。

---

## 修改內容

### 1. 新增 `GetSchoolCounty()`

於 `Form2.cs` 新增方法，從資料庫取得學校所在地縣市。

- **SQL 來源**：`list` 資料表，`name = '學校資訊'`
- **XML 來源**：`content` 欄位
- **XML 節點**：`/SchoolInformation/County`
- **回傳**：`countyNode.InnerText.Trim()`；失敗或空值時回傳空字串

```sql
SELECT content
FROM list
WHERE name = '學校資訊'
LIMIT 1
```

錯誤與空值處理（不中斷報表產生）：

1. SQL 查不到資料
2. `content` 為 null 或空白
3. XML 沒有 `<County>`
4. XML 格式錯誤
5. SQL 或 XML 解析 Exception → `Debug.WriteLine("取得學校所在地縣市失敗：" + ex.Message)` 後回傳空字串

### 2. `LocalCounty` 改為呼叫 `GetSchoolCounty()`

```csharp
#region 按戶籍地分

string LocalCounty = GetSchoolCounty();
```

### 3. 本縣市 / 其他縣市判斷方式（維持原邏輯）

```csharp
foreach (myStudent student in summary)
{
    if (student.County == LocalCounty)
    {
        collect__LocalCounty.Add(student);   // 戶籍位於本縣市
    }
    else
    {
        collect__OtherCounty.Add(student);  // 戶籍非位於本縣市
    }
}
```

學生戶籍縣市仍來自 `permanent_address` → `AddressList` → `Address` → `County`，本次未修改。

Excel 輸出位置維持不變：

- `cs[39, 6]`：戶籍位於本縣市
- `cs[40, 6]`：戶籍非位於本縣市
- 後續男女統計、各入學方式統計位置皆未改動
