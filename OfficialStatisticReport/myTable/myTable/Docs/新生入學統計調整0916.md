# 新生入學統計調整紀錄（2025/09/16）

## 1. 修改檔案

- `Form2.cs`
  - `linkLabel1_LinkClicked`（「重設」連結）：改寫重設流程

未修改：

- `LoadConfigXml()`（開啟表單時的正常載入）
- `SaveMappingXmlRecord()`（列印時儲存）
- `BindConfigMappingsToGrid()`（僅於重設時以 `config = null` 重用）
- 報表產生、Excel 匯出、學生篩選、Tag ID 轉換等其餘邏輯

## 2. 原始重設行為

舊版 `linkLabel1_LinkClicked`：

1. 以 `AccessHelper` 讀取並刪除 `myTableUDT`（舊 UDT 對應資料）。
2. 僅清除 `dataGridViewX1` 列。
3. 呼叫 `LoadConfigXml()`，從 Config（`新生入學統計報表_來源目標設定Config`）還原對應。

問題：

- 未一併清除 X2 / X3。
- 重設仍依賴舊 Config，畫面會立刻帶回舊來源對應。
- 無法依「目前 Student Tag」同名狀態重設為預設。
- UDT 刪除與現行 Config 儲存流程無關，不應作為重設手段。

## 3. 新重設行為

新流程：

```text
清除 X1 / X2 / X3 列
        ↓
清除三個 Source ComboBox Items（避免重複）
        ↓
Column3Prepare() 重載最新 Student Tag 來源
        ↓
BindConfigMappingsToGrid(..., config: null, ...) × 3
        ↓
僅以預設 Target + 完全同名 Source 自動填入
```

實作要點：

1. **三個 DataGridView 一併清除**：`dataGridViewX1` / `X2` / `X3`。
2. **重載 Student Tag 來源**：先 `Items.Clear()`，再 `Column3Prepare()`（查詢 `tag where category='Student'`）。
3. **不重跑 Target Prepare**：`Column2Prepare` / `dataGridViewComboBoxExColumn2Prepare` / `dataGridViewComboBoxExColumn3Prepare` 不呼叫，避免 Target 選項重複累加；重用建構時已準備好的 Target 集合。
4. **重用 `BindConfigMappingsToGrid`，傳入 `config = null`**：不載入舊 Config；僅當 Source 清單含與 Target **完全相同**（`StringComparer.Ordinal`）的文字時自動填入，否則 Source 留空。
5. **重設不呼叫 `LoadConfigXml()`**。
6. **重設不呼叫 `SaveMappingXmlRecord()`**，也不直接覆寫 Config。
7. **移除重設時的 UDT 刪除**（`AccessHelper` / `DeletedValues`）。

## 4. 與 Config 的關係

| 時機 | Config 行為 |
|---|---|
| 按「重設」 | 僅變更畫面；**不讀取**舊 Config 對應、**不寫入** Config |
| 關閉表單（未列印） | 重設後的畫面變更不會自動寫回 Config |
| 按列印（`buttonX1_Click` → `SaveMappingXmlRecord()`） | 以當前畫面對應寫入 Config（既有流程不變） |

## 5. 完全同名比對

沿用既有邏輯：

```csharp
HashSet<string> sourceSet =
    new HashSet<string>(sourceItems, StringComparer.Ordinal);

// ...
else if (sourceSet.Contains(target))
    source = target;
```

不使用部分比對、模糊比對或大小寫忽略。

## 6. 驗證結果

依 `Docs/Todo_修改重設.md` 驗收項目，以程式碼審查確認：

| 項目 | 結果 |
|---|---|
| 重設清除 X1/X2/X3 列 | 通過（三處 `Rows.Clear()`） |
| 重設重載最新 Student Tag 來源 | 通過（Clear + `Column3Prepare()`） |
| 重複重設不產生重複 Source | 通過（重設前先 Clear Items） |
| X1/X2/X3 預設 Target 還原 | 通過（重用既有 Target Items + `BindConfigMappingsToGrid`） |
| 有完全同名 Source → 自動填入 | 通過（`config == null` 時走同名分支） |
| 無同名 Source → 空白 | 通過 |
| 重設不還原舊 Config 對應 | 通過（不呼叫 `LoadConfigXml()`；`config = null`） |
| 重設不立即儲存／覆寫 Config | 通過（不呼叫 `SaveMappingXmlRecord()`） |
| 列印／報表邏輯未刻意變更 | 通過（僅改 `linkLabel1_LinkClicked`） |

執行期建議再手動確認：改 Student Tag 後按重設可刷新來源下拉；重設多次列數不變；有自訂 Config 時重設畫面不同於 Config，關閉未列印後再開應仍為舊 Config。
