# 新生入學統計調整紀錄（2025/09/16）

## A. 報表輸出結構重構（本次）

### 1. 修改檔案

- `Form2.cs`
  - 學生查詢 SQL：加入 `dept.code`、`dept_group.name`
  - `Export()`：改為直接載入完整樣板活頁簿，並依部別寫入各工作表
  - 新增 `WriteErrorSheet()`、`WriteDepartmentSheet()`
- `Filter.cs`
  - 改以 `dept_group.name` 路由至 5 個報表工作表
  - 分組鍵改為 `科別代碼⊕科別名稱⊕班別`

  - 新增 `Dept_code`、`Dept_group_name`

- `CheckStudentStatus()`、新生異動代碼 `< 100` 規則

### 2. 原始活頁簿匯出行為

舊版 `Export()`：

1. `new Workbook()` 後再 `Worksheets.Add()`，手動建立 `異常資料表`
2. 另外開啟樣板 `新生入學方式統計表_樣板`
3. 只複製樣板第 0 張工作表：`_wk.Worksheets[0].Copy(wk2.Worksheets[0])`
4. 重新命名為 `新生入學方式統計表`

結果：輸出只剩 1 張統計表 + 1 張異常表，樣板中的 5 個部別工作表會遺失。

### 3. 新的完整樣板載入行為

```csharp
_wk = new Workbook();
_wk.Open(
    new MemoryStream(
        Properties.Resources.新生入學方式統計表_樣板
    )
);
```

不再建立空白活頁簿、不再只複製第 0 張、不再改名為 `新生入學方式統計表`。

### 4. 保留的 6 個工作表名稱

```text
普通科
專業群科(職業科)
綜合高中
實用技能學程
進修部(學校)
異常資料表
```

一次列印輸出一個 Excel 檔，內含上述全部工作表。

### 5. `dept_group` 關聯與部別分類

SQL：

```sql
left join dept_group
    on dept.ref_dept_group_id = dept_group.id
```

讀取：

```sql
dept_group.name AS dept_group_name
```

路由規則：

```text
dept_group.name
    ↓
對應同名工作表
    ↓
寫入該工作表統計
```

`dept_group.name` 為空，或不在上述 5 個支援工作表名稱內 → 進 `異常資料表`，不列入正常統計。

### 6. `dept.code` 來源與排序

SQL 讀取：

```sql
dept.code AS dept_code
```

分組鍵：

```text
dept_code ⊕ dept_name ⊕ ClassType
```

各工作表內以 `dept_code` 數值排序；同代碼再以 `ClassType` 穩定排序。

不再依 `ORDER BY dept_name` 或 Dictionary 列舉順序決定報表列序。

### 7. 科別解析優先順序

維持：

```text
student.ref_dept_id 有值 → 用學生科別
student.ref_dept_id 為 null → 用 class.ref_dept_id
```

### 8. 班別（ClassType）來源

維持來自新生異動：

```xml
ContextInfo/ClassType
```

SQL：

```sql
TRIM(update_record_info.Class_Type) AS Class_Type
```

同科別、不同 ClassType 分開成列。

### 9. 實際招生班數

`Filter.getClassCount()`：

```text
同部別 + 同科別 + 同班別分組內
    ↓
收集 ref_class_id
    ↓
排除 null / 空白
    ↓
Distinct Count
```

### 10. 入學方式／入學身分

維持既有 Tag 對應流程：

```text
DataGridView Target / Source
        ↓
ReadXMLMappingData()
        ↓
Source → tag.id
        ↓
XML_mappingData
        ↓
filter.getListByTagId(...)
```

11 種入學方式、4 種入學身分定義未改。

### 11. 異常資料表路由

使用樣板既有工作表：

```csharp
_wk.Worksheets["異常資料表"]
```

至少在下列情況列入異常、且不進正常統計：

- 無法判定科別（`dept_name` 空白）
- 科別代碼缺失（`dept_code` 空白）
- 部別缺失或無法對應 5 個支援工作表
- 班別代碼不在對照表
- 既有基本欄位異常（姓名、性別、班級等）

## B. 重設行為調整（同日稍早）

### 1. 修改檔案

- `Form2.cs`
  - `linkLabel1_LinkClicked`（「重設」連結）：改寫重設流程

未修改：

- `LoadConfigXml()`（開啟表單時的正常載入）
- `SaveMappingXmlRecord()`（列印時儲存）
- `BindConfigMappingsToGrid()`（僅於重設時以 `config = null` 重用）
- 報表產生、Excel 匯出、學生篩選、Tag ID 轉換等其餘邏輯

### 2. 原始重設行為

舊版 `linkLabel1_LinkClicked`：

1. 以 `AccessHelper` 讀取並刪除 `myTableUDT`（舊 UDT 對應資料）。
2. 僅清除 `dataGridViewX1` 列。
3. 呼叫 `LoadConfigXml()`，從 Config（`新生入學統計報表_來源目標設定Config`）還原對應。

問題：

- 未一併清除 X2 / X3。
- 重設仍依賴舊 Config，畫面會立刻帶回舊來源對應。
- 無法依「目前 Student Tag」同名狀態重設為預設。
- UDT 刪除與現行 Config 儲存流程無關，不應作為重設手段。

### 3. 新重設行為

新流程：

```text
清除 X1 / X2 / X3 列
        ↓
清除三個 Source ComboBox Items（避免重複）
        ↓
Column3Prepare() 重載最新 Student Tag 來源
        ↓
BindConfigMappingsToGrid(..., config: null, ...) × 3
        ↓
僅以預設 Target + 完全同名 Source 自動填入
```

實作要點：

1. **三個 DataGridView 一併清除**：`dataGridViewX1` / `X2` / `X3`。
2. **重載 Student Tag 來源**：先 `Items.Clear()`，再 `Column3Prepare()`（查詢 `tag where category='Student'`）。
3. **不重跑 Target Prepare**：`Column2Prepare` / `dataGridViewComboBoxExColumn2Prepare` / `dataGridViewComboBoxExColumn3Prepare` 不呼叫，避免 Target 選項重複累加；重用建構時已準備好的 Target 集合。
4. **重用 `BindConfigMappingsToGrid`，傳入 `config = null`**：不載入舊 Config；僅當 Source 清單含與 Target **完全相同**（`StringComparer.Ordinal`）的文字時自動填入，否則 Source 留空。
5. **重設不呼叫 `LoadConfigXml()`**。
6. **重設不呼叫 `SaveMappingXmlRecord()`**，也不直接覆寫 Config。
7. **移除重設時的 UDT 刪除**（`AccessHelper` / `DeletedValues`）。

### 4. 與 Config 的關係

| 時機 | Config 行為 |
|---|---|
| 按「重設」 | 僅變更畫面；**不讀取**舊 Config 對應、**不寫入** Config |
| 關閉表單（未列印） | 重設後的畫面變更不會自動寫回 Config |
| 按列印（`buttonX1_Click` → `SaveMappingXmlRecord()`） | 以當前畫面對應寫入 Config（既有流程不變） |

### 5. 完全同名比對

沿用既有邏輯：

```csharp
HashSet<string> sourceSet =
    new HashSet<string>(sourceItems, StringComparer.Ordinal);

// ...
else if (sourceSet.Contains(target))
    source = target;
```

不使用部分比對、模糊比對或大小寫忽略。
